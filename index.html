Import

Paste comma-separated rows below, one workout set per line:
date,category,exercise,reps,weight,notes,equipment,amrap

  • For time-based rows: put the time in the reps column and duration in seconds in the weight column.
  • For bodyweight rows: put bw in the weight column.
  • Equipment defaults to "Other" if left blank.
  • amrap column accepts yes/true/1.
  • Optional summary line to set a workout's calories/effort:
    #SUMMARY,date,category,activeCalories,totalCalories,effort
Example: 
2026-06-01,Upper Body Push Day,Bench Press,8,135,felt strong,Barbell,no
2026-06-01,Upper Body Push Day,Push-ups,20,bw,,Other,no
